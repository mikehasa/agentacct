# agent-acct

**This is an alias package. The real project is [`agentacct`](https://pypi.org/project/agentacct/).**

`agent-acct` and `agentacct` are two different names on PyPI, so this package
exists to make the hyphenated spelling work. It contains no code of its own —
installing it installs `agentacct`:

```bash
pip install agent-acct    # works, but pulls in agentacct
pip install agentacct     # preferred — install the real name directly
```

Either way you end up with the `agentacct` command:

```bash
agentacct onboard
```

## What agentacct is

Local-first Agent Work Intelligence for coding agents: usage truth, recorded
work, and honest joins.

Docs, source, and issues: **https://github.com/mikehasa/agentacct**
